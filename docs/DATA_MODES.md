# REACT-X Data Modes & Provenance Policy

**Document Version:** 1.0.0  
**Phase:** 19 — End-to-End System Integration, Connectivity & Operational Orchestration  

---

## 1. Data Mode Isolation Rules

1. **LIVE:**
   - Originates from authenticated external satellite passes or verified on-premise industrial gateways.
   - Requires valid credentials.
   - Always has `is_simulated = False`.

2. **REFERENCE:**
   - Originates from verified historical industrial baselines (e.g. Dahej PetroChem Alpha golden dataset).
   - Used for benchmark comparisons and regression testing.

3. **SIMULATION:**
   - Generated by software simulation adapters (`telemetry_simulator`, `camera_simulator`).
   - Carries `is_simulated = True` and explicit `scenario_id`.
   - Never displayed in the UI as real live industrial alerts.

4. **MIXED:**
   - Ingests partial live telemetry alongside simulated secondary visual feeds.
   - Every individual evidence item in the `IncidentPacket` explicitly records its distinct `data_mode` and source provenance.
